## What you get

Reply Style makes a thread's replies easier to scan. Quote bars are grey rather than the theme's accent, a spoiler's summary has a chevron and a hover state, spoilers open and close smoothly, and nested lists get a thin guide line down each level, with an elbow to each nested item, spoiler and quote, so the evidence under an item reads as part of it.

## Settings

**Reply Style** in a thread's actions menu opens a settings panel over the chat (also the plugin's page in BB's settings), with tabs for quotes, spoilers, lists and tables: switches for **Guide Lines**, **Elbows**, **Path Numbers**, **Dim Markers**, **Spoiler As Quote** and **Tables Surface**, and sliders for each strength, width and the open time. A slider restyles the replies behind it while you drag.

## Cost

One stylesheet, limited to the timeline's rendered messages. No script watches the page; the plugin writes an attribute or a custom property on the page root only for a setting off its default.
